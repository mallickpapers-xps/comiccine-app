# ComicCine - Cinematic Comics Reader

A Flutter app that transforms static comics into cinematic experiences.

## Features
- Import CBZ, CBR, PDF, and image files
- AI-powered panel and bubble detection
- Cinematic presentation mode
- Video player-style controls
- Manual storyboard editor
- 100% offline, zero cost

## Build APK
Push to GitHub and the APK will be built automatically via GitHub Actions.
